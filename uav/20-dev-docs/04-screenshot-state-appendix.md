# 状态与截图对照附录

## 使用原则

- 这一附录服务于开发者日常排查，不替代完整说明书。
- 当前仓库中的原始图片多数是算法 README 图、仿真 gif 或模块演示图，不能直接当作实机日常操作截图。
- 因此这里分成两部分：一部分写当前已经能引用的证据，一部分明确需要补采的实机画面。

## 起飞前

- 应同时展示遥控器 5/6/7/8 通档位，至少能一眼看出当前是否满足 onboard + 轨迹模式 + 已解锁的自动起飞前置条件。
- 应展示起飞前终端或 rviz 的关键状态，重点是 `/mavros/state`、`/mavros/battery`、`/mavros/rc/in` 三项联合观测。
- 应提示开发者在起飞前先确认定位链已经稳定输出，LIO 看 `/ekf/ekf_odom`，VIO 看 `/vins/imu_propagate`。
- 当前可引用的原始证据主要来自本地知识库中的遥控器通道说明和状态观测命令，不存在一张已经整理好的“起飞前状态总图”。

## 手动悬停与接管

- 应展示 5 通和 6 通切换后的状态语义，至少覆盖 onboard、姿态、光流和悬停兜底四种判断。
- 应提示出现异常时优先上拨 6 通回悬停，再按需要切 5 通或 7 通。
- 应提示开发者观察 `/mavros/rc/in`，确认当前不是软件逻辑错误，而是 RC 档位没满足安全门。
- 当前仓库里只有遥控器通道文字说明，没有成套的“接管前后对照图”。

## 自主执行

- 应展示任务启动后 rviz 中的轨迹、点云和当前位置关系。
- 应提示开发者同步检查 `/drone_0_planning/trajectory`、`/setpoints_cmd`、`/ekf/ekf_odom` 或 `/vins/imu_propagate`。
- 当前可引用的素材包括 `Diff-planner/images/rviz_test.gif` 和 `Diff-planner/images/navigation.gif`，但这两份更偏算法演示，不应当替代实机日常判断图。
- 当前更可靠的文字证据来自本地知识库对 LIO/VIO 主链和规划 topic 的整理。

## 返航与降落

- 应展示返航触发和降落触发的两种方式：脚本触发与 RC 8 通触发。
- 应提示开发者检查 `/back_trigger`、`/px4ctrl/takeoff_land`、`/mavros/state`，确认系统是否真正进入返航或降落动作。
- 应展示落地后如何判断任务真正结束，例如轨迹停止刷新、状态稳定、动力系统已安全退出。
- 当前没有一套现成的“返航前后”和“降落完成后”对照截图，需要补采。
