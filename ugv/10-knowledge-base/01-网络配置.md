# 01 - 无人车网络配置

来源：`OS-mate-网络配置.pdf`。当前为手册配置整理，后续以现场实机 `ip addr`、路由器后台和雷达后台为准。

## 网络拓扑

当前采用无线桥接方案：

```text
Mac / ground station
  -> 主 Wi-Fi / 主路由 192.168.0.1
  -> 小车路由器无线桥接到主 Wi-Fi
  -> 小车工控机静态 IP: 192.168.0.<ipc>
  -> 3D 激光雷达静态 IP: 192.168.0.<lidar>
```

小车路由器出厂管理地址：

```text
http://192.168.1.1
password: 12345678
```

桥接完成后，小车路由器会被主路由分配一个新的 `192.168.0.xxx` 管理 IP。之后要访问小车路由器后台，需要连接主 Wi-Fi，并访问这个新 IP。

## 配置流程

### 1. 小车路由器无线桥接

1. 电脑先连接小车 Wi-Fi。
2. 浏览器打开 `192.168.1.1`。
3. 登录密码 `12345678`。
4. 进入 `应用管理` -> `无线桥接`。
5. 扫描并选择主 Wi-Fi，输入主 Wi-Fi 密码。
6. 桥接完成后记录弹窗提示的新管理 IP，通常是 `192.168.0.xxx`。
7. 电脑重新连接主 Wi-Fi。

如果扫描无线信号卡住，先点取消，再刷新重新扫描。

### 2. 修改 3D 激光雷达 IP

雷达配置后台默认地址：

```text
http://192.168.1.200
```

在小车 Ubuntu 系统里打开浏览器，进入雷达后台 `Setting`，修改：

| 字段 | 含义 | 设置规则 |
|---|---|---|
| `Device IP Address` | 雷达本机 IP | 改为主 Wi-Fi 网段 `192.168.0.<lidar>` |
| `Device IP Gateway` | 雷达网关 | `192.168.0.1` |
| `Destination IP Address` | 点云目标 IP | 小车工控机 IP `192.168.0.<ipc>` |

`Device IP Address` 和 `Destination IP Address` 必须不同，且同一主路由下所有车、雷达、工控机不能冲突。

### 3. 修改小车工控机有线 IP

在 Ubuntu 桌面：

1. 右上角有线网络图标。
2. 进入有线设置。
3. 进入当前有线连接设置。
4. IPv4 选择 `手动`。
5. 地址设置为雷达 `Destination IP Address`，即 `192.168.0.<ipc>`。
6. 网关设置为 `192.168.0.1`。
7. 应用后关闭/重新打开有线网络。
8. 新终端执行 `ifconfig` 或 `ip addr` 确认 IP。

## 三车 IP 编址建议

当前主路由网段按手册为 `192.168.0.0/24`，网关为 `192.168.0.1`。为了后续三车三机统一管理，建议固定分段：

| 平台 | 路由器管理 IP | 工控机 IP | 3D 雷达 IP | 备注 |
|---|---:|---:|---:|---|
| UGV-1 | `192.168.0.111` | `192.168.0.121` | `192.168.0.131` | 当前第一台车可按现场实际替换 |
| UGV-2 | `192.168.0.112` | `192.168.0.122` | `192.168.0.132` | 第二台车 |
| UGV-3 | `192.168.0.113` | `192.168.0.123` | `192.168.0.133` | 第三台车 |

如果主路由 DHCP 会自动分配路由器管理 IP，建议在主路由后台做 DHCP 地址保留；否则至少在总表里记录桥接后分配到的实际 IP。

## 验证命令

Mac 或地面站连接主 Wi-Fi 后：

```bash
ping <工控机新IP>
ssh yhs@<工控机新IP>
```

车端工控机：

```bash
ip addr
ip route
ping 192.168.0.1
ping <雷达IP>
```

如果 ROS 需要跨机调试 Rviz：

```bash
export ROS_MASTER_URI=http://<工控机IP>:11311
export ROS_HOSTNAME=<地面站IP>
```

## 大系统接入含义

- 每台车仍然保留自己的 ROS master。
- 网络层统一接入同一个主 Wi-Fi 网段，方便地面站 SSH、rsync、日志采集和 gateway 通信。
- 平台 gateway 应绑定到工控机 IP，而不是雷达 IP 或路由器管理 IP。
- 雷达 `Destination IP Address` 必须指向本车工控机 IP，否则点云可能发不到车端 ROS 驱动。
