## 底盘速度控制

底盘驱动包：`yhs_can_control`。

启动命令需要实机确认，手册出现过两种写法：

```bash
roslaunch yhs_can_control yhs_can_control.launch.py
roslaunch yhs_can_control yhs_can_control.launch
```

底盘速度话题：

```bash
rostopic info /smoother_cmd_vel
rostopic pub -r 50 /smoother_cmd_vel geometry_msgs/Twist ...
```

接入策略：平台网关默认不要直接开放任意速度控制。若必须开放，应加速度、角速度、时长、遥控器状态和障碍状态限制。

## 导航目标控制

导航启动：

```bash
roslaunch yhs_nav yhs_nav_2d.launch
roslaunch yhs_nav yhs_nav.launch
```

编程接口是 ROS `move_base` action，依赖 `move_base_msgs` 和 `actionlib`。手册示例中目标可以基于 `base_link` 下发相对前进 1m。

接入策略：

- 平台网关对外暴露 `navigate_to_pose`、`cancel_navigation`、`navigation_status`。
- 中心 PDDL 不直接发 `/smoother_cmd_vel`，只发任务级目标。
- 车端本地 BT 执行 `send_goal -> monitor -> success/fail/cancel`。

## 回充服务

文档给出的服务：

```bash
rosservice call /recharge ...
rosservice call /dis_recharge ...
```

需要实机确认 service type、参数字段和安全前提。该能力需要配套充电桩，不能默认所有车都有。

## 远程操作

默认 SSH 线索：

```bash
ssh yhs@192.168.1.102
```

NoMachine 前置命令：

```bash
sudo systemctl stop gdm3.service
sudo systemctl restart nxserver.service
```

Rviz 跨机方式需要设置：

```bash
export ROS_HOSTNAME=<笔记本IP>
export ROS_MASTER_URI=http://192.168.1.102:11311
```

实际 IP、账号和密码以现场机器为准。
