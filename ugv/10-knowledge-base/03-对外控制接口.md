# 03 - 对外控制接口

状态标记：

- `[M]` 手册确认
- `[C]` 实车代码或运行时确认
- `[?]` 仍需实机验证

## 控制入口优先级

| 层级 | 接口 | 建议用途 | 状态 |
|---|---|---|---|
| 任务级 | `move_base` action | 中心任务系统下发导航目标 | [C] |
| 任务级 | `/move_base_simple/goal` | Rviz / 简单目标点入口 | [C] |
| 任务级 | Rviz 插件多点/录制路径 | 人工调试、原厂流程 | [M] |
| 安全级 | `/move_base/cancel` | 取消当前导航目标 | [C] |
| 底盘级 | `/cmd_vel` | `move_base` 到速度平滑器的原始速度 | [C] |
| 底盘级 | `/smoother_cmd_vel` | 速度平滑器到底盘驱动 | [C] |
| 服务级 | `/recharge` | 回充动作，默认未随 `yhs_nav.launch` 启动 | [C] |
| 服务级 | `/dis_recharge` | 脱离充电桩，默认未随 `yhs_nav.launch` 启动 | [C] |
| 状态级 | `/chassis_info_fb` | FW 底盘反馈 | [C] |
| 状态级 | `/odom` | 里程计 topic | [C] |
| 状态级 | `map -> base_link` TF | 3D/NDT 模式下平台位姿 | [C] |
| 状态级 | `/imu_data` | IMU | [C] |
| 状态级 | `/tmlidar_points` | 3D 激光点云 | [M] |

## 底盘速度控制

底盘驱动包：`yhs_can_control`。

实车确认启动文件：

```bash
roslaunch yhs_can_control yhs_can_control.launch
```

实车确认速度链路：

```bash
/move_base -> /cmd_vel -> /velocity_smoother -> /smoother_cmd_vel -> /yhs_can_control_node -> can0
```

接入策略：平台网关默认不要直接开放任意速度控制。`/cmd_vel` 和 `/smoother_cmd_vel` 只保留给本地安全停止、诊断和原厂调试流程。

## 导航目标控制

导航启动：

```bash
roslaunch yhs_nav yhs_nav_2d.launch
roslaunch yhs_nav yhs_nav.launch
```

编程接口是 ROS `move_base` action，依赖 `move_base_msgs` 和 `actionlib`。手册示例中目标可以基于 `base_link` 下发相对前进 1m。

接入策略：

- 平台网关对外暴露 `navigate_to_pose`、`cancel_navigation`、`navigation_status`。
- 中心 PDDL 不直接发 `/smoother_cmd_vel`，只发任务级目标。
- 车端本地 BT 执行 `send_goal -> monitor -> success/fail/cancel`。
- 当前 3D/NDT 模式应使用 `map` 坐标系；`odom -> base_link` TF 不存在是预期行为。

## 状态字段

`/chassis_info_fb` 的实车类型是 `yhs_msgs/FwChassisInfoFb`。Gateway 首版状态字段：

- `is_unlocked = io_fb.io_fb_unlock`
- `estop_active = io_fb.io_fb_estop`
- `charge_state = io_fb.io_fb_charge_state`
- `battery_soc = bms_flag_fb.bms_flag_fb_soc`
- `battery_voltage = bms_fb.bms_fb_voltage`
- `battery_current = bms_fb.bms_fb_current`
- `gear = ctrl_fb.ctrl_fb_gear`
- `linear_feedback = ctrl_fb.ctrl_fb_linear`
- `angular_feedback = ctrl_fb.ctrl_fb_angular`

## 回充服务

文档给出的服务：

```bash
rosservice call /recharge ...
rosservice call /dis_recharge ...
```

实车代码确认 service type：

- `/recharge`: `recharge/Recharge`, fields `float32 recharge_x`, `float32 recharge_y`, `float32 recharge_yaw`
- `/dis_recharge`: `recharge/DisRecharge`, field `std_msgs/String dis_recharge`

该能力需要配套充电桩，不能默认所有车都有。`yhs_nav.launch` 默认没有启动 `recharge_node`。

## 远程操作

默认 SSH 线索：

```bash
ssh yhs@192.168.1.102
```

NoMachine 前置命令：

```bash
sudo systemctl stop gdm3.service
sudo systemctl restart nxserver.service
```

Rviz 跨机方式需要设置：

```bash
export ROS_HOSTNAME=<笔记本IP>
export ROS_MASTER_URI=http://192.168.1.102:11311
```

实际 IP、账号和密码以现场机器为准。
