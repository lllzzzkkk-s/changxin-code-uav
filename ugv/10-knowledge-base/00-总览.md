# 00 - 无人车总览

基于 `OS-mate 机器人开发平台 用户使用手册 V1.0.2` 的初版整理，后续需要用实机代码和 ROS graph 校验。

## 平台定位

- 厂商/平台：深圳煜禾森 OS-mate 机器人开发平台。
- 系统：Ubuntu 20.04 + ROS Noetic。
- 默认源码目录：`/home/yhs/catkin_ws/src`。
- 控制栈形态：ROS1 Navigation / `move_base` 为核心，不是 PX4/MAVROS 风格。
- 本阶段建议定位：把无人车作为一个平台 ROS master，通过 platform gateway 暴露任务级接口给中心 PDDL/BT。

## 主要能力

- 底盘 CAN 驱动与速度控制。
- IMU 数据发布与里程计航向修正。
- 2D 建图：Gmapping / Cartographer。
- 3D 建图：3D 激光 + IMU，文档流程使用 LIO-SAM 离线 bag 建图。
- 2D/3D 导航：`move_base`，支持 Rviz 单点、多点、录制路径。
- 障碍物图层：3D 激光；可加入深度相机点云转 LaserScan。
- 可选回充：ROS service `/recharge` 和 `/dis_recharge`，需要配套充电桩。

## 和无人机系统的关键差异

无人机链路是 `PX4 + MAVROS + px4ctrl + planner`，车端链路更像：

```text
operator / platform gateway
  -> move_base action or /move_base_simple/goal
  -> global/local planner
  -> /smoother_cmd_vel
  -> yhs_can_control
  -> CAN can0
  -> chassis VCU
```

因此大系统接入时，车端优先暴露任务级导航接口，而不是直接暴露底盘速度接口。

## 当前结论

- 对外任务入口首选 `move_base` action。
- 低层速度入口是 `/smoother_cmd_vel`，只应作为急停/短距离调试/底盘健康检查使用。
- 车端安全前提包括遥控器切到指令模式、CAN 正常、定位初始化完成、`odom received`。
- 工控机软件重启后 CAN 可能不可用，文档强调需要断电重启恢复。
